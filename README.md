# Trainer Assistant

Telegram Mini App + бот — помічник тренера для офлайн-тренувань. Клієнти записуються особисто в тренера, а тренер веде все в додатку: календар, клієнтів, абонементи, оплати; бот надсилає нагадування, ранковий план, повідомлення листа очікування й розсилки.

## Що вміє

| Розділ | Тренер | Клієнт |
| --- | --- | --- |
| Календар | слоти (індивідуальні / групові з лімітом), постійні серії, копіювання тижня, перетини | вільно / зайнято / свій запис / «залишилось N з M», 🔔 лист очікування |
| Клієнти | картки (також без Telegram), підтвердження гостей, прив'язка Telegram, реферал, нотатки, травми | анкета першого входу зі згодою |
| Відвідування й гроші | «прийшов / неявка / скасовано» зі списанням з абонемента, пробне, оплати, абонементи, журнал змін | залишок занять, найближчі записи, історія |
| Аналітика | дохід, завантаження, відвідуваність, конверсія пробних, абонементи, що закінчуються | — |
| Ціни | разові заняття й абонементи, порядок, приховування | перегляд, кнопка «Записатися у тренера» |
| Бот | `/today`, `/broadcast` (розсилка з попереднім переглядом), ранковий план о 08:00 | `/start`, нагадування за 3 години, «звільнилось місце» |

Мови: українська (за замовчуванням), російська. Тема — з Telegram. Час — Europe/Kyiv.

## Структура

```
server/           Node.js + Fastify + Drizzle ORM (PostgreSQL) — API, бот, планувальник
server/drizzle/   SQL-міграції; застосовуються автоматично при старті
web/              React + Vite — інтерфейс Mini App
```

## Ролі та безпека

- Кожен запит до `/api/*` несе підписаний Telegram `initData`; сервер перевіряє підпис токеном бота.
- Роль обчислюється на кожному запиті: **тренер** — лише за `TRAINER_TELEGRAM_IDS`; **клієнт** — якщо картка `ACTIVE`; інакше **гість**.
- Усі маршрути тренера перевіряються на сервері; тест `guards.test.ts` падає, якщо новий маршрут не віднесено до тренерських або клієнтських.
- Webhook бота приймає лише запити із секретним заголовком.
- `DEV_AUTH_BYPASS` сервер відмовляється вмикати в production.

## Змінні оточення

Сервер (Railway):

| Змінна | Опис |
| --- | --- |
| `DATABASE_URL` | PostgreSQL |
| `BOT_TOKEN` | токен бота від @BotFather (секрет) |
| `TRAINER_TELEGRAM_IDS` | Telegram ID тренера, кілька — через кому |
| `WEB_ORIGIN` | адреса інтерфейсу (Vercel) — для CORS і кнопки «Відкрити додаток» |
| `NODE_ENV` | `production` |
| `RAILWAY_PUBLIC_DOMAIN` | задається Railway автоматично; з нього налаштовується webhook (або `PUBLIC_URL`) |

Інтерфейс (Vercel): `VITE_API_URL` — адреса сервера.

## Розробка

```bash
npm install
cp server/.env.example server/.env   # заповнити
npm run dev:server
npm run dev:web
npm test                              # тести сервера на справжньому Postgres у пам'яті (PGlite)
```

Зміна схеми: правка `server/src/db/schema.ts` → `npm run db:generate -w server` → закомітити нову міграцію.
